# Madmoon App - Project Resources

## Overview

This folder is dedicated to supporting documentation and resources for the Madmoon App graduation project.

Madmoon is a Flutter application for managing product warranties, purchase receipts, and warranty expiration reminders.

## Project Resources

The project resources may include:

- **Application Screenshots:** Screenshots of the login, registration, dashboard, warranty management, and notification screens.
- **Database Documentation:** Information about the Supabase PostgreSQL database and its warranty records.
- **System Architecture:** Documentation describing the connection between Flutter, Supabase Authentication, PostgreSQL, and Supabase Storage.
- **Testing Documentation:** Information about application testing and verification.

## Main Project Files

The application source code is organized in the main repository:

- `lib/` - Flutter application source code.
- `lib/screens/` - Application screens.
- `lib/services/` - Notification service.
- `android/` - Android application configuration.
- `test/` - Automated test files.
- `pubspec.yaml` - Flutter dependencies.

## Security

Supabase configuration values are stored locally in `supabase_config.json`, which is excluded from Git tracking.

No passwords, private credentials, or Supabase secret keys should be included in this folder.
